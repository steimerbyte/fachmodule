## 2. Wirtschaft – Überblick

**Wirtschaft** umfasst alle **Aktivitäten zur Deckung menschlicher Bedürfnisse** mit knappen Gütern.

**Begriffe:**

- **Bedürfnis**: Mangel an Gütern (Grundbedürfnisse, Luxusbedürfnisse)
- **Gut**: Mittel zur Bedürfnisbefriedigung
- **Knappheit**: Güter sind begrenzt verfügbar
- **Ökonomisches Prinzip**: Mit gegebenen Mitteln den Nutzen maximieren

---

## 3. Bedürfnisse und Güter

### 3.1 Bedürfnisarten

- **Existenzbedürfnisse**: Nahrung, Kleidung, Wohnung
- **Kulturbedürfnisse**: Bildung, Kunst
- **Luxusbedürfnisse**: Reisen, Schmuck
- **Soziale Bedürfnisse**: Gemeinschaft, Anerkennung

### 3.2 Güterarten

| Art | Beschreibung | Beispiel |
|---|---|---|
| **Freie Güter** | unbegrenzt verfügbar | Luft, Sonnenlicht |
| **Wirtschaftsgüter** | knapp, arbeitsteilig hergestellt | Autos, Brot |
| **Verbrauchsgüter** | gehen unter | Lebensmittel |
| **Gebrauchsgüter** | dauerhaft nutzbar | Maschinen |
| **Produktionsgüter** | zur Herstellung | Rohstoffe |
| **Konsumgüter** | für Endverbraucher | Kleidung |

### 3.3 Bedürfnisbefriedigung

- Knappe Güter werden in Märkten gehandelt
- Preismechanismus regelt Angebot und Nachfrage
- Ökonomisches Prinzip: maximiere Output mit gegebenen Ressourcen

---

## 4. Produktionsfaktoren

### 4.1 Klassische Produktionsfaktoren

- **Arbeit**: menschliche Arbeitsleistung
- **Boden**: Natur, Rohstoffe
- **Kapital**: Maschinen, Gebäude, Geld

### 4.2 Erweiterte Produktionsfaktoren

- **Wissen**: Humankapital, Patente
- **Information**: Daten als Produktionsmittel
- **Entrepreneurship**: unternehmerische Initiative

### 4.3 Funktion

Produktionsfaktoren werden kombiniert, um Güter und Dienstleistungen herzustellen.

## 5. Wirtschaftskreislauf

### 5.1 Modell

Der **Wirtschaftskreislauf** zeigt die Ströme zwischen **Haushalten** und **Unternehmen**.

```
       Haushalte               Unternehmen
       (Konsumenten)            (Produzenten)
            │                        │
            │  ←  Konsum            │
            │                        │
            │  →  Arbeitskraft      │
            │                        │
            │  →  Boden/Pacht      │
            │                        │
            │  →  Kapital          │
            │                        │
            │  ←  Güter/Dienst-    │
            │      leistungen       │
            │                        │
            │  ←  Löhne/Profit     │
            │                        │
```

### 5.2 Ströme

- **Güterströme**: Güter und Dienstleistungen fließen
- **Geldströme**: Einkommen fließt zurück
- **Produktionsfaktorströme**: Arbeit, Boden, Kapital

### 5.3 Geschlossener Kreislauf

- Summe der Geldströme = Summe der Güterströme (in Geld bewertet)
- Volkswirtschaftliche Gesamtrechnung (VGR)

### 5.4 Erweiterungen

- **Staat**: erhebt Steuern, gibt Subventionen
- **Ausland**: Exporte, Importe
- **Banken**: Kredite, Geldmenge

## 7. Zusammenfassung

**Wirtschaft** ist die **Lehre von der Güterproduktion und -verteilung** zur Bedürfnisbefriedigung:

**Grundbegriffe:**

- Bedürfnis (Mangel)
- Gut (Mittel)
- Knappheit
- Ökonomisches Prinzip

**Produktionsfaktoren:**

- Arbeit, Boden, Kapital
- Wissen, Information

**Wirtschaftskreislauf:**

- Haushalte ↔ Unternehmen
- Güterströme ↔ Geldströme
