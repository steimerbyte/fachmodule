## 3. Bruttoinlandsprodukt (BIP)

### 3.1 Definition

Das **Bruttoinlandsprodukt** misst den **Wert aller Güter und Dienstleistungen**, die innerhalb einer Periode **innerhalb der Landesgrenzen** produziert werden.

### 3.2 Berechnungsansätze

#### Entstehungsrechnung (Produktionsansatz)

```
BIP = Summe der Bruttowertschöpfung aller Sektoren
```

#### Verwendungsrechnung (Ausgabenansatz)

```
BIP = C + I + G + (Ex - Im)
```

- **C**: Konsum (Private Haushalte)
- **I**: Investitionen (Unternehmen)
- **G**: Staatsausgaben
- **Ex - Im**: Außenbeitrag (Export minus Import)

#### Verteilungsrechnung (Einkommensansatz)

```
BIP = Löhne + Gewinne + Steuern - Subventionen + Abschreibungen
```

### 3.3 Reales vs. nominales BIP

- **Nominales BIP**: in laufenden Preisen
- **Reales BIP**: in konstanten Preisen (Inflation bereinigt)
- BIP-Wachstum = reales Wachstum

### 3.4 BIP pro Kopf

```
BIP pro Kopf = BIP / Bevölkerung
```

Maß für Wohlstand, aber nicht für Verteilung.

## 4. Konjunkturzyklus

### 4.1 Phasen

```
Aufschwung → Boom/Hochkonjunktur → Abschwung → Rezession → Tal/Abschwung → Aufschwung
```

### 4.2 Indikatoren

- **Frühindikatoren**: Auftragseingänge, Geschäftserwartungen
- **Präsenzindikatoren**: BIP, Produktion
- **Nachläufer**: Arbeitslosenzahl

### 4.3 Konjunkturpolitik

- **In Boomphase**: bremsen (z. B. Zinsen erhöhen)
- **In Rezession**: stützen (z. B. Zinsen senken, Steuern senken)

## 5. Geld und Inflation

### 5.1 Geldfunktionen

- **Tauschmittel**
- **Wertaufbewahrungsmittel**
- **Rechnungseinheit**

### 5.2 Geldmenge

- **M0**: Bargeld
- **M1**: M0 + Sichteinlagen
- **M2**: M1 + Termineinlagen bis 2 Jahre
- **M3**: M2 + Spareinlagen

### 5.3 EZB und Geldpolitik

- **Hauptrefinanzierungszinssatz**: Leitzins
- Offenmarktgeschäfte
- Einlagenfazilität, Spitzenrefinanzierungsfazilität
- Anleihekäufe (Quantitative Easing)
- Inflationsziel: 2 % (EZB)

### 5.4 Inflation

```
Inflationsrate = (Preis(heute) - Preis(vorperiode)) / Preis(vorperiode) × 100 %
```

**Ursachen:**

- **Nachfrageinflation**: zu viel Geld, zu wenig Güter
- **Angebotsinflation** (Kosteninflation): gestiegene Produktionskosten
- **Importierte Inflation**: Wechselkurseffekte

**Folgen:**

- Geldentwertung
- Unsicherheit
- Gläubiger/Schuldner-Umverteilung

## 6. Arbeitsmarkt

### 6.1 Arbeitslosenquote

```
ALQ = Anzahl Arbeitslose / Erwerbspersonen × 100 %
```

### 6.2 Arten von Arbeitslosigkeit

- **Friktionelle**: Übergang zwischen Jobs
- **Strukturelle**: Mismatch zwischen Qualifikation und Angebot
- **Konjunkturelle**: durch Konjunkturabschwung
- **Saisonale**: witterungsbedingt, Sommer/Winter

### 6.3 Okun'sches Gesetz

```
Δ Arbeitslosenquote ≈ -0,5 × Δ BIP-Wachstum
```

## 7. Fiskal- und Geldpolitik

### 7.1 Fiskalpolitik

- **Staatseinnahmen** (Steuern, Abgaben)
- **Staatsausgaben** (Konsum, Investitionen)
- **Konjunkturwirkung**: anti- oder prozyklisch
- **Stabilisierung**: automatische Stabilisatoren (z. B. Arbeitslosengeld)

### 7.2 Geldpolitik

- Verantwortlich: **EZB** (Euroraum), **Fed** (USA), **Bundesbank** (historisch)
- **Instrumente**: Zinssatz, Offenmarktgeschäfte, Mindestreserve

### 7.3 Zusammenspiel

- **Fiscal Dominance**: Fiskalpolitik dominiert
- **Monetary Dominance**: Geldpolitik dominiert
- **Unabhängigkeit**: Notenbank unabhängig

## 9. Zusammenfassung

**Makroökonomie** betrachtet die **Volkswirtschaft als Ganzes**:

**Wichtige Konzepte:**

- **BIP**: Wohlstandsmaß
- **Konjunkturzyklus**: Auf und Ab der Wirtschaft
- **Inflation**: Geldentwertung
- **Arbeitslosigkeit**: ungenutztes Arbeitskräftepotenzial
- **Fiskal- und Geldpolitik**: Stabilisierungsinstrumente

**Zentrale Akteure:**

- **EZB**: Geldpolitik im Euroraum
- **Bundesregierung**: Fiskalpolitik
