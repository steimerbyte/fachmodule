## 2. Entscheidungsfindung – Überblick

**Entscheidungsfindung** ist die **strukturierte Auswahl** zwischen mehreren Alternativen.

**Phasen:**

1. Problem definieren
2. Informationen sammeln
3. Alternativen entwickeln
4. Bewerten
5. Entscheiden
6. Umsetzen
7. Kontrollieren

## 3. Klassische Analyseverfahren

### 3.1 ABC-Analyse

- **A**: wichtigste 20 % (70 % Anteil)
- **B**: mittlere 30 % (20 % Anteil)
- **C**: unbedeutende 50 % (10 % Anteil)
- Anwendung: Pareto-Prinzip

### 3.2 Nutzwertanalyse (NWA)

- Kriterien mit Gewichtung
- Bewertung der Alternativen
- siehe Fachmodul 3582

### 3.3 Kosten-Nutzen-Analyse

- Monetäre Bewertung
- Investitionsrechnung
- siehe Fachmodul 3343

### 3.4 Break-Even-Analyse

```
Break-Even-Punkt = Fixkosten / (Preis - variable Kosten)
```

## 4. Portfolio-Analyse

### 4.1 BCG-Matrix

| | Hoher Marktanteil | Niedriger Marktanteil |
|---|---|---|
| **Hohes Marktwachstum** | Stars (Sterne) | Question Marks (Fragezeichen) |
| **Niedriges Marktwachstum** | Cash Cows (Milchkühe) | Poor Dogs (Hunde) |

**Strategien:**

- Stars: halten, Marktanteil sichern
- Cash Cows: melken, Gewinne abschöpfen
- Question Marks: investieren oder aufgeben
- Dogs: aufgeben oder Nischen besetzen

### 4.2 McKinsey/GE-Matrix

- 9-Felder-Matrix
- Mehrere Faktoren
- Branchenattraktivität vs. Wettbewerbsstärke

## 5. SWOT-Analyse

### 5.1 Aufbau

| | Hilfreich | Schädlich |
|---|---|---|
| **Intern** | Strengths (Stärken) | Weaknesses (Schwächen) |
| **Extern** | Opportunities (Chancen) | Threats (Risiken) |

### 5.2 Anwendung

- Strategische Planung
- Projektbewertung
- Persönliche Karriereplanung

### 5.3 Beispiel (KMU)

**Strengths**: erfahrenes Team, gute Kundenbeziehungen
**Weaknesses**: begrenzte Liquidität, alte IT-Systeme
**Opportunities**: Digitalisierung, neue Märkte
**Threats**: Wettbewerber, Cyber-Risiken

## 8. Zusammenfassung

**Analyseverfahren** strukturieren die **Entscheidungsfindung**:

**Methoden:**

- **ABC-Analyse**: Pareto-Prinzip
- **Nutzwertanalyse**: gewichtete Kriterien
- **Kosten-Nutzen-Analyse**: monetär
- **Break-Even-Analyse**: Gewinnschwelle
- **BCG-Matrix**: Portfolio
- **SWOT-Analyse**: Stärken/Schwächen/Chancen/Risiken
- **PEST**: Makro-Umfeld
- **Porter's Five Forces**: Wettbewerbsanalyse
