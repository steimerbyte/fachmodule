## 2. Kennzahlen und KPIs

### 2.1 Kennzahlen

- **Quantitative** Maße für Unternehmensleistung
- Beispiele: Umsatz, Gewinn, Mitarbeiterzahl

### 2.2 KPIs (Key Performance Indicators)

- **Schlüsselkennzahlen** für kritische Erfolgsfaktoren
- SMART formuliert
- Beispiel: Kundenzufriedenheit, Lieferzeit

### 2.3 Klassifikation

| Typ | Beschreibung | Beispiel |
|---|---|---|
| **Finanzielle KPI** | monetär | Umsatz, ROI |
| **Kunden-KPI** | Kunden-bezogen | NPS, Beschwerdequote |
| **Prozess-KPI** | intern | Durchlaufzeit, Fehlerquote |
| **Mitarbeiter-KPI** | Personal | Fluktuation, Zufriedenheit |
| **Nachhaltigkeits-KPI** | ESG | CO2, Lieferanten-Compliance |

## 3. Balanced Scorecard (BSC)

### 3.1 Konzept

Die **Balanced Scorecard** (Kaplan/Norton) verbindet **vier Perspektiven** für eine ausgewogene Bewertung.

### 3.2 Vier Perspektiven

| Perspektive | Kernfrage | Beispiele |
|---|---|---|
| **Finanzen** | Wie erscheinen wir unseren Aktionären? | Umsatz, ROI |
| **Kunden** | Wie sehen uns unsere Kunden? | Zufriedenheit, Marktanteil |
| **Interne Prozesse** | Wo müssen wir besser werden? | Durchlaufzeit, Qualität |
| **Lernen und Entwicklung** | Können wir verbessern? | Schulungen, Innovation |

### 3.5 Aufbau

Jede Perspektive enthält:

- **Strategische Ziele**
- **Kennzahlen**
- **Vorgaben (Targets)**
- **Initiativen/Maßnahmen**

### 3.6 Beispiel

```
Finanzen:
- Ziel: 12 % EBIT-Marge
- KPI: EBIT-Marge
- Target: 12 %
- Initiative: Kostenoptimierung

Kunden:
- Ziel: Top-Anbieter für KMU
- KPI: NPS-Wert
- Target: 50+
- Initiative: Kundenumfragen ausbauen

Prozesse:
- Ziel: Schnellere Lieferung
- KPI: Durchlaufzeit
- Target: < 7 Tage
- Initiative: Lean-Prozesse

Lernen & Entwicklung:
- Ziel: Höhere Innovationskraft
- KPI: Anzahl neuer Produkte pro Jahr
- Target: 3
- Initiative: F&E-Budget erhöhen
```

### 3.7 Vorteile

- Ausgewogene Bewertung
- Verknüpfung Strategie ↔ operative Maßnahmen
- Kommunikation der Strategie

## 4. Objectives and Key Results (OKR)

### 4.1 Konzept

**OKR** (von Andy Grove bei Intel entwickelt, populär durch Google) besteht aus:

- **Objective**: qualitatives Ziel (inspirierend)
- **Key Results**: 2-5 messbare Ergebnisse

### 4.2 Beispiel

```
Objective: "Wir werden Marktführer in Deutschland"

Key Results:
- KR1: Marktanteil von 25 % auf 35 % steigern
- KR2: 5 Mio. EUR Umsatz pro Quartal erreichen
- KR3: NPS von 40 auf 55 steigern
- KR4: Top-3-Platzierung in „Best Places to Work"
```

### 4.3 Eigenschaften

- **Ambitioniert**: 60-70 % Erreichung als Erfolg
- **Transparent**: alle Mitarbeiter sehen alle OKRs
- **Vierteljährlich**: häufiger Zyklus
- **Smart**: nicht zu starr

### 4.4 BSC vs. OKR

| Aspekt | BSC | OKR |
|---|---|---|
| Anzahl Perspektiven | 4 | unbegrenzt |
| Hierarchie | stark | schwach |
| Frequenz | jährlich | quartalsweise |
| Anspruch | realistisch | ambitioniert |
| Ursprung | Strategie | Ausführung |

## 5. Performance Measurement

### 5.1 Datenerfassung

- **Manuell**: Excel, Fragebogen
- **Automatisch**: ERP, CRM, MES
- **Sensoren**: IoT, Betriebsdatenerfassung

### 5.2 Visualisierung

- **Dashboard**: Echtzeit-Anzeige
- **Reports**: regelmäßige Berichte
- **Ampel**: rot/gelb/grün für Schwellenwerte
- **Sparklines, Heatmaps, Trends**

### 5.3 Tools

- **Power BI**: Microsoft
- **Tableau**: Standard
- **Qlik**: QlikView, Qlik Sense
- **Looker**: Google
- **Grafana**: Open Source
- **Excel, Power BI**: kleine Lösungen

### 5.4 Herausforderungen

- **Datensilos**: Daten sind nicht integriert
- **Datenschutz** (DSGVO)
- **Datensicherheit**
- **Datenqualität**

## 7. Zusammenfassung

**Performance Measurement** ist die **Quantifizierung** der Zielerreichung:

**Kennzahlen:**

- Finanzielle, Kunden-, Prozess-, Mitarbeiter-KPIs
- SMART formuliert

**Methoden:**

- **BSC**: 4 Perspektiven, jährlich
- **OKR**: Objectives + Key Results, quartalsweise

**Tools:** Power BI, Tableau, Qlik, Grafana

### Selbsttest-Checkliste

- [ ] Ich definiere KPIs SMART.
- [ ] Ich erstelle eine Balanced Scorecard.
- [ ] Ich formuliere OKRs.
- [ ] Ich nutze Performance-Tools.
