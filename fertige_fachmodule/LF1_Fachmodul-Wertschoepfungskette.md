## 2. Wertschöpfungskette nach Porter

Michael Porter (Harvard) definiert die **Wertschöpfungskette** (Value Chain) als Modell zur Analyse der **wertschöpfenden Tätigkeiten** eines Unternehmens.

```
┌─────────────────────────────────────────┐
│ Unterstützungsaktivitäten                │
│ ┌─────────────────────────────────┐     │
│ │ HR, Tech, Beschaffung, Infra     │     │
│ │ ┌──────────┐                     │     │
│ │ │ Eingangs-│ Logistik Operations Marketing │     │
│ │ │ logistik │        │              │     │
│ │ │   → Service →                    │     │
│ │ │           │                      │     │
│ │ │   ← Marketing & Vertrieb        │     │
│ │ └──────────┘                     │     │
│ └─────────────────────────────────┘     │
└─────────────────────────────────────────┘
        MARGE
```

**Marge** = Wert - Kosten

## 3. Primäraktivitäten

### 3.1 Eingangslogistik (Inbound Logistics)

- Wareneingang, Lagerung
- Lieferantenmanagement
- Materialfluss

### 3.2 Operationen (Produktion)

- Herstellung, Montage, Verpackung
- Qualitätskontrolle

### 3.3 Marketing und Vertrieb

- Marktforschung, Werbung
- Vertriebskanäle, Verkauf

### 3.4 Service

- Kundendienst
- Garantie, Reparatur
- Schulung

---

## 4. Unterstützungsaktivitäten

### 4.1 Beschaffung

- Einkauf von Material, Dienstleistungen
- Lieferantenbeurteilung

### 4.2 Technologieentwicklung

- F&E, Innovation
- IT-Systeme
- Prozessoptimierung

### 4.3 Personalmanagement (HR)

- Recruiting, Ausbildung
- Personalentwicklung
- Vergütung

### 4.4 Unternehmensinfrastruktur

- Geschäftsführung, Controlling
- Finanzen, Recht
- Qualitätsmanagement

---

## 5. Wertschöpfung im IT/Dienstleistungs-Unternehmen

### 5.1 Besonderheiten

- **Dienstleistung** statt Sachgut
- **Kunde ist oft Mitproduzent**
- **Immaterielle Wertschöpfung**
- **Wissensarbeit**

### 5.2 Angepasste Wertschöpfung

- **Eingangslogistik**: Wissensbeschaffung, Lizenzen
- **Operationen**: Entwicklung, Implementierung
- **Marketing**: Lead-Generierung, Pitches
- **Service**: Support, Wartung

---

## 6. Beispiele

### 6.1 Beispiel Apple

- **Beschaffung**: Lieferanten für Komponenten
- **Entwicklung**: F&E, Design
- **Produktion**: Foxconn in China
- **Marketing**: Brand, Stores
- **Service**: AppleCare, Genius Bar

### 6.2 Beispiel McDonald's

- **Eingangslogistik**: Fleisch, Brötchen
- **Operationen**: standardisierte Küche
- **Marketing**: global einheitlicher Markenauftritt
- **Service**: Drive-in, McDelivery

### 6.3 Beispiel Lufthansa

- **Eingangslogistik**: Treibstoff, Catering
- **Operationen**: Flugbetrieb, Wartung
- **Marketing**: Vielflieger-Programm
- **Service**: Check-in, Lounge

## 8. Zusammenfassung

Die **Wertschöpfungskette nach Porter** analysiert alle wertschöpfenden Tätigkeiten:

**Primäraktivitäten:**

- Eingangslogistik, Operationen
- Marketing, Service

**Unterstützungsaktivitäten:**

- Beschaffung, Technologie, HR
- Infrastruktur

**Marge** = Wert - Kosten

**IT-Bereich:** Wissensarbeit, immaterielle Wertschöpfung
