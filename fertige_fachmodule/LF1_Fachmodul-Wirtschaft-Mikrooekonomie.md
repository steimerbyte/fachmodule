## 2. Mikroökonomie – Überblick

**Mikroökonomie** untersucht das **Verhalten einzelner Wirtschaftssubjekte** (Haushalte, Unternehmen) und die **Bildung von Preisen** auf einzelnen Märkten.

**Gegensatz:** Makroökonomie (gesamtwirtschaftliche Zusammenhänge).

## 3. Konsumentenverhalten

### 3.1 Nutzen und Präferenzen

- **Nutzen**: subjektives Maß für die Befriedigung
- **Grenznutzen**: zusätzlicher Nutzen durch eine weitere Einheit
- **Abnehmender Grenznutzen**: jedes weitere Stück bringt weniger

### 3.2 Nutzenfunktion

U(x₁, x₂) = Gesamtnutzen aus Konsum von x₁ und x₂

### 3.3 Indifferenzkurven

Kombinationen von Gütern mit gleichem Nutzen:

```
x₁ │        IC₁ IC₂ IC₃
   │          /  /  /
   │         /  /  /
   │        /  /  /
   │       /  /  /
   └──────────────── x₂
```

### 3.4 Budgetrestriktion

- Konsument hat begrenztes Einkommen
- Budgetlinie: p₁x₁ + p₂x₂ = m
- Maximaler Nutzen unter Budgetrestriktion

## 4. Produzentenverhalten

### 4.1 Produktionsfunktion

Q = f(K, L)

- Q: Output
- K: Kapital
- L: Arbeit

### 4.2 Ertragsgesetz

- **Zunehmender Ertrag**: Produktivität steigt
- **Abnehmender Ertrag**: Produktivität sinkt bei weiterem Input
- Bei klassischer Produktion: erst zunehmend, dann abnehmend

### 4.3 Kostenfunktion

- **Fixkosten**: unabhängig von Produktionsmenge
- **Variable Kosten**: abhängig von Menge
- **Grenzkosten**: zusätzliche Kosten für eine weitere Einheit

### 4.4 Durchschnittskosten

K(x) = K(x) / x

## 5. Marktformen und Wettbewerb

### 5.1 Polypol

- Viele Anbieter, viele Nachfrager
- Homogene Produkte
- Vollständige Markttransparenz
- **Preisnehmer**

### 5.2 Monopol

- **Ein** Anbieter, viele Nachfrager
- Preissetzungsmacht
- **Gewinnmaximierung** bei Grenzerlös = Grenzkosten
- Beispiel: Deutsche Bahn (Regionalverkehr)

### 5.3 Oligopol

- Wenige Anbieter
- **Wettbewerb** und Absprachen
- Beispiel: Telekommunikation, Airlines, Mineralöl
- **Preisabsprachen** (Kartell) sind verboten

### 5.4 Monopson

- **Ein** Nachfrager, viele Anbieter
- Beispiel: Rüstungsindustrie

### 5.5 Vergleich

| | Polypol | Monopol | Oligopol |
|---|---|---|---|
| Anbieter | viele | einer | wenige |
| Preis | gegeben | frei | strategisch |
| Wettbewerb | perfekt | keiner | strategisch |

## 7. Zusammenfassung

**Mikroökonomie** erklärt **individuelles Verhalten** und **Marktbildung**:

**Konsumenten:**

- Nutzenfunktion, Indifferenzkurven
- Budgetrestriktion

**Produzenten:**

- Produktionsfunktion
- Ertragsgesetz
- Kostenfunktion

**Marktformen:**

- **Polypol**: vollständige Konkurrenz
- **Monopol**: ein Anbieter
- **Oligopol**: wenige Anbieter
- **Monopson**: ein Nachfrager
